Transparency for Removed Reviews

Open-source platform mapping Google review removals to reveal patterns and support research into takedown practices.

Neutral, evidence-based, and non-accusatory.

View on GitHub Learn More

Platform Features

A privacy-preserving transparency platform that aggregates and verifies review removal incidents while protecting user privacy.

🛡️

Privacy-First Design

Zero PII leaks in public views. All submissions are carefully anonymized while preserving research utility.

🔍

Verification System

Cryptographic and header-level verification of email sources through DKIM/DMARC validation and manual moderation.

🗺️

Global Mapping

Interactive map visualization of removal incidents with business profiles and geographic analysis capabilities.

📊

Pattern Analysis

AI-powered analysis of removal notices to identify patterns and trends in takedown practices across regions.

📈

Open Research

Quarterly transparency reports and open anonymized datasets to support journalism, NGOs, and academic research.

⚖️

Legal Compliance

Built with DSA requirements in mind, supporting policy debate through evidence-based transparency.

Technology Stack

Built with modern, scalable technologies ensuring security, performance, and maintainability.

🐍

Backend

FastAPI with PostgreSQL/PostGIS, Celery workers, and comprehensive API documentation.

⚛️

Frontend

Next.js 14 with TypeScript, Tailwind CSS, and server-side rendering for optimal performance.

🗄️

Database

PostgreSQL with PostGIS for geographic data and advanced spatial query capabilities.

☁️

Infrastructure

Docker containers with Redis caching, MinIO storage, and GitHub Actions CI/CD.

🔐

Security

JWT authentication, DKIM/DMARC validation, and comprehensive access control.

📧

Integration

Mailgun API for email processing and automated submission workflow.
